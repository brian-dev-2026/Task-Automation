Auto Child Tasks

Paste a numbered list of child tasks; it adds, starts and finishes all of them on your main task.

1. Install (once)

  1. Show your bookmarks bar: press Ctrl+Shift+B.
  2. Drag this green button onto the bookmarks bar:
    Auto Child Tasks

2. Use

  1. Open Programmer Task and log in.
  2. Click Auto Child Tasks on your bookmarks bar. A panel opens on the right.
  3. Pick the main task (it must be On-going).
  4. Paste your child tasks, numbered:
    1. refactored uploading
    2. refactored downloading
  5. Check the preview, then click Add, start & finish.

Target to Start and Target to Finish are set to today (a Sunday start or weekend finish moves to Monday). If some tasks fail, only those stay in the box, so clicking the button again retries just them. Click the bookmark again to close the panel.
